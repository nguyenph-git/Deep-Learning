WEEK 7 · RNNs, LSTM, GRU (sequential data)

Probability of sequences

Chain rule: p(x1:T) = p(x1) ∏t p(xt | x1:t−1)
1st-order Markov: p(x1:n) = p(xn|xn−1)…p(x2|x1)p(x1)  (only previous item)
  • RNN = autoregressive model; ht = g(ht−1, xt) is a lossy summary of x1:t. Pre-DL: HMM, Kalman filter, DBN, CRF.

Simple RNN (same U, W, V shared over time)

h0 = tanh(x0U + b)    ht = tanh(ht−1W + xtU + b)
ŷt = htV + c (regression)  |  softmax(htV + c) (classification)
Total loss = Σt l(ŷt, yt)
U:[in, hid]   W:[hid, hid]   V:[hid, out]
Trap: x is always multiplied by U, h by W, output uses V. "h1=tanh(h0W+x1V+b)" and "y=hU+c" are WRONG.

Parameter counting

RNN cell: in·h + h·h + h  → in=10, h=5: 10×5 + 5×5 + 5 = 80
LSTM = 4 × (in·h + h² + h)    GRU = 3 × (in·h + h² + h)
(PyTorch keeps 2 bias vectors: +h per gate block)   Embedding = vocab × emb   Linear = in·out + out

BPTT & vanishing gradient

∂L/∂h0 = Σt ∂losst/∂ŷt · ∂ŷt/∂ht · diag(1−h̄t²)W ⋯ diag(1−h̄1²)W
  • Product of many W ⇒ vanishing/exploding gradients ⇒ RNN only captures short-term dependency. Fix = gating (add a linear path) → LSTM/GRU.
  • BPTT: unroll, forward & store, backprop from last step, sum local gradients per parameter, then SGD.

LSTM (Hochreiter & Schmidhuber ’97)

ft = σ(xtUf + ht−1Wf + bf)   it = σ(…i)   ot = σ(…o)
gt = tanh(xtU + ht−1W + b)
ct = ft ⊙ ct−1 + it ⊙ gt  (long-term)    ht = ot ⊙ tanh(ct)  (short-term)
  • 3 gates use sigmoid (0–1 proportion); candidate g uses tanh. 4 FC blocks.
  • Forget: proportion of long-term ct−1 carried forward. Input: how much of gt stored. Output: proportion of current long-term ct passed to new short-term ht.

GRU (Cho et al. 2014, built for encoder–decoder)

zt = σ(xtUz + ht−1Wz)   rt = σ(xtUr + ht−1Wr)
gt = tanh(xtUg + (rt ⊙ ht−1)Wg)    ht = (1−zt) ⊙ ht−1 + zt ⊙ gt
  • Merges c and h into one state; single update gate z = forget+input (z=1: open input / close forget); no output gate; reset gate r controls how much of the previous state is used. z, r → 1 ⇒ basic RNN.

Shapes (the most-asked quiz type)

Input ids [B, L] → Embedding [B, L, emb] → each RNN/GRU layer [B, L, its own hidden] → Flatten [B, L·h] → Linear [B, out]
  • out, h_n = nn.GRU(...)(x): out = [B, L, h] (all steps); h_n = [layers, B, h]. Sequence-first form [L, B, in] ⇒ torch.transpose(X,0,1).
  • Embedding lookup = one-hot 1i × E = row i of E. Sentiment: (B,L)→(B,L,emb)→(B,L,128)→(B,128) last state→(B,1) sigmoid ≥0.5 pos.
  • Char-level text generation: x0='*' start, '$' end; max log-lik = min Σ CE at each step; output = #chars neurons.

Topologies

  • many→one: sentiment analysis, sequence classification · one→many: image captioning · many→many (enc–dec, delayed): machine translation · many→many (synced): frame-level video classification.
★ Week 7 key concepts (what the quiz tests)
  • 1st-order Markov: each item depends only on the one before it: p(xn|xn−1)…p(x2|x1)p(x1).
  • Parameter count = in×h (U) + h×h (W) + h (bias). Input 10, hidden 5 → 50 + 25 + 5 = 80.
  • Input x is always multiplied by U, previous state h by W, output by V; the same U and W are reused at every time step.
  • Topologies: sentiment = many→one · captioning = one→many · translation = many→many (encoder–decoder) · frame-level video = many→many (synced).
  • Shapes: embedding gives [B, L, emb]; every RNN/GRU layer gives [B, L, its own hidden size] (L unchanged); Flatten gives [B, L×h] (5×16 = 80); Linear gives [B, out].
  • h, _ = gru(x) keeps the all-steps output [B, L, h], not just the last state.
  • All LSTM gates use sigmoid. Forget gate = share of long-term ct−1 kept. Output gate = share of the current long-term ct passed into the new short-term ht.

WEEK 8 · Word embedding, Word2Vec

Classical text features

  • Pipeline: normalise → features (tf-idf, word2vec) → model (NB, SVM / LDA / k-means) → metrics (Acc, P/R; ROUGE, BLEU; NMI, Silhouette).
  • Normalisation: expand contractions (isn't→is not), lemmatisation (cars→car, running→run, is→be), remove special chars, remove stop words.
  • Bag-of-words: doc = Σ one-hot(words) = counts; stacked = term-by-document matrix.
idf(t,C) = log(|C| / |Ct|)  (|Ct| = #docs containing t)    smoothed: log((1+|C|)/(1+|Ct|))
tfidf(t,d,C) = tf(t,d) × idf(t,C)    L2-normalise: v / √(v1²+…+vn²)
natural log: ln2 = 0.69. Term in every doc ⇒ idf = 0. Ex: [0.69,0,0,0.69,0] → [0.71,0,0,0.71,0]

Representation learning

  • Hand-crafted (SIFT/HOG/TF-IDF, extractor disconnected from classifier) vs DL (automatic, connected). Supervised rep = fits one downstream task; unsupervised = general.
  • Self-supervised: invent a pretext task to turn raw data into supervised learning (e.g. predict rotation 0/90/180/270 → 4 labels). Word2Vec's pretext task: predict neighbours ("know a word by the company it keeps" – Firth).

Skip-gram (target → context)

U ∈ ℝN×d (input→hidden), V ∈ ℝd×N (hidden→output), N = vocab size, d = embedding size
h = 1tU = Ut (row t of U)   o = hV ∈ ℝ1×N   p = softmax(o)
log p(cw=c | tw=t) = UtV:,c − log Σk exp(UtV:,k)
J(θ) = ∏t=1..T ∏−C≤j≤C, j≠0 p(wt+j | wt; θ)  → maximise; t = index of centre word
  • Training pairs: (brown,the), (brown,quick), (brown,fox), (brown,jumps) for C=2.
  • Drawbacks: softmax over huge N is expensive; probabilities tiny & hard to distinguish; depends on window size. Fixes: hierarchical softmax O(V)→O(log V), negative sampling.

Negative sampling

p = sigmoid(o) (binary, NOT a distribution)   max log pc − α log pn1 − α log pn2
  • Positive pair [(tw,cw),1] → maximise prob of being positive; random negatives [(tw,ng),0] → minimise prob of predicting them as positive.

CBOW (context → target)

h = ¼(1c1+1c2+1c3+1c4)U = average of context rows of U; o = hV; p = softmax(o)
J(θ) = ∏t p(wt | wt−C,…,wt−1,wt+1,…,wt+C)   window size = 2C+1

Using embeddings

Analogy: argminv ‖vCanberra − vAustralia + vParis − v‖ = vFrance;  cosine similarity for nearest words
  • Init an RNN's embedding matrix with pretrained Word2Vec, then fine-tune (vs train from scratch).
  • doc2vec: doc matrix D[N×p] + word matrix W[M×q], average/concat, predict word. node2vec: random walks = sentences. BFS = local/microscopic, DFS = global/macroscopic; p = return param, q = walk-away param; low p → BFS-like, low q → DFS-like. Also item2vec, med2vec, topic2vec…
Traps: vocabulary/dictionary size N = #unique words (10k), not #sentences. Embedding size d is a free hyper-parameter (NOT the window size). Skip-gram input = one-hot of the target; CBOW input = average of context one-hots.
★ Week 8 key concepts (what the quiz tests)
  • Skip-gram: the centre word predicts each context word. CBOW: the context words predict the centre word. Window 7 = centre + 3 words each side.
  • Analogy by vector arithmetic: king − prince ≈ queen − princess.
  • One-hot = 1 at the word's index (check whether the dictionary starts at 0 or 1).
  • Vocabulary size N = number of unique words, not sentences. Embedding size d is a chosen setting; the window size doesn't determine it.
  • Skip-gram drawbacks: softmax over N is expensive; probabilities are tiny and hard to tell apart; results depend on the window size.
  • Negative sampling: sigmoid output (outputs don't sum to 1); push (target, context) towards positive and (target, random word) away from positive.
  • ∏t∏j≠0 p(wt+j|wt) = skip-gram objective (t = centre word, maximise). p(wt|wt−C…t+C) = CBOW objective, window = 2C+1.
  • U is [N, d], V is [d, N]. Skip-gram: input = one-hot of the target, h = that row of U. CBOW: input = average of the context one-hots, h = average of their rows.
  • Reading a toy network: vocab size = rows of U, embedding size = columns. A probability is the softmax output at the context word's index, not the raw score o = hV.

WEEK 9 · Seq2Seq, Attention, Transformer, BERT

Encoder–decoder / seq2seq

  • Encoder encodes input sequence → context c = hTx (last encoder hidden state) summarising x. Decoder reads c → output sequence. In MT both are RNNs. Apps: MT, image captioning (CNN enc), code translation, QA.
maxθ Σ(x,y) log P(y|x,θ), θ = [θe, θd]
P(y|x) = P(y1:Ty|c) (1)= ∏j P(yj | y1:j−1, c) (2)= ∏j P(yj | qj−1, c)
  • (1): c summarises x1:Tx. (2): qj−1 summarises y1:j−1. P(yj|qj−1,c) = dense layers on top of qj−1, c (output = vocab+1).
  • Variants: qj−1 = f(qj−2, yj−1) [Sutskever] or f(qj−2, concat(c, yj−1)) [Cho]; f = LSTM/GRU. Big drawback: c fixed across timesteps.
  • Inference: phase 1 feed x to encoder to get c; phase 2 init decoder state with c (last encoder hidden), feed <BOS>, stop at <EOS>. Greedy = pick argmax each step (not sampling). Beam search (k): keep top-k partial sequences by joint probability; finish when each beam outputs <EOS>; return best.

Attention (timely-varied context ct)

  • Fixed c is a bottleneck, overwhelmed by long inputs; ct focuses on the input words most relevant to the current output word.
Global: ct = Σs at(s) h̄s over ALL encoder states; at(s) = softmaxs score(qt, h̄s)
score: dot qtTh̄s | general qtTWah̄s | concat vaTtanh(Wa[qt; h̄s])
q̃t = tanh(Wc[ct; qt])    p(yt|y<t,x) = softmax(Wsq̃t)
Local: window [pt−D, pt+D] of encoder states; pt = S·sigmoid(vpTtanh(Wpqt)) ∈ [0,S]
at(s) = align(qt, h̄s) · exp(−(s−pt)² / 2σ²), σ = D/2
  • Global = expensive for long sequences. Local = linear combination of encoder states in a window. Largest weight at(s) = most important input word.

Transformer

  • RNN problems: slow (sequential), poor long-range. Transformer: no recurrence/conv → parallel, great long-range; order recovered by positional encoding. GPT = Generative Pre-trained Transformer.

Self-attention

Q = XWQ, K = XWK, V = XWV   (X: [L, dmodel], dQ = dK)
scores B = QKT/√dk [L,L]   probs A = softmax(B, dim=−1) [L,L]   Z = AV [L, dV]   out = ZWO [L, dmodel]
  • Bij = Qi·Kj ≈ sim(xi, xj); Q, K are two other "views" of X. zi depends mainly on xi but every xj contributes; more similar xj → more contribution. Cost O(L²).
  • Multi-head: each head has its own WQ,WK,WV, computed independently in parallel; concat heads → extra linear WO.
  • Masked SA (decoder is causal): B.masked_fill(mask==0, −inf) on future positions → softmax gives 0 there.
  • Cross-attention: Q = Y WQ from decoder; K, V from encoder output X. B: [B, tgt_len, src_len]. Injects encoder output into decoder; part of decoder output only.

WEEK 9 (cont.) · Transformer blocks, BERT

Other blocks

PE(pos,2i) = sin(pos/100002i/d)   PE(pos,2i+1) = cos(pos/100002i/d)   → added to token embeddings
LayerNorm(Y) = γ (Y − mean)/std + β, stats over embedding dim (dmodel) of each token
Pointwise FFN: Z̄ = ReLU(ZW1 + b1)W2 + b2 (same FFN per token)
  • Encoder block: MHSA → Add&LayerNorm (residual) → FFN → Add&LayerNorm; shape [B, L, dmodel] kept, ×n blocks. Decoder: masked MHSA → cross-attn → FFN, then Linear+softmax.
  • LN has learnable γ, β; better than BatchNorm for variable-length sequences. PE encodes position of a token in a sentence (not sentence in batch); it is not the embedding itself.

BERT (encoder-only, pretrain + fine-tune)

  • Pretrain 1: masked LM – 15% of tokens chosen: 80% → [MASK], 10% → random word, 10% unchanged. Pretrain 2: next sentence prediction – 50% IsNext / 50% NotNext, predicted from [CLS] vector C.
  • Fine-tune all params. Classification: P = softmax(WC), W ∈ ℝM×h. Span QA: Pi = exp(STTi)/Σjexp(STTj), learn start S and end E vectors. Works because: Transformer + huge data + many params.
★ Week 9 key concepts (what the quiz tests)
  • The encoder turns the input into context c (a summary of the input); the decoder reads c to produce the output. In MT both are RNNs and c = last encoder hidden state.
  • In the factorisation, c summarises x1:Tx and qj−1 summarises y1:j−1; P(yj|qj−1, c) = dense layers on top of them. Feeding c only at the start or at every step are both valid.
  • Decoding: encode to get c → start the decoder from the last encoder hidden state → first input <BOS> → greedy = take the argmax at each step (no sampling).
  • A time-varying context beats a fixed one: it copes with long inputs and focuses on the input words relevant to the current output.
  • Global attention = weighted sum of all encoder states; local = weighted sum of the encoder states inside a window. Never decoder states.
  • ct = Σ at(s) h̄s; the largest weight marks the most important input word.
  • Positional encoding = position of a token in the sentence, added to the embeddings. LayerNorm normalises over dmodel, has learnable γ, β, and beats BatchNorm on sequences.
  • Self-attention: zi comes mostly from xi but every xj contributes; more similar xj gets more weight. Scores B come from Q and K, shape [L, L]; A = softmax(B); Z = AV (not BV).
  • Multi-head attention: each head has its own WQ, WK, WV and runs independently; heads are concatenated, then passed through WO.
  • Cross-attention: Q from the decoder, K and V from the encoder output; it feeds encoder information into the decoder (decoder side only).

WEEK 10 · Vision Transformers, Swin, Fine-tuning

Self- vs cross-attention

  • Self: source = target; Q, K, V from the same (source) sequence; captures intra-sequence dependencies. Cross: Q from target, K & V from source; inter-sequence. Both compute token embeddings in parallel. Attention ≈ soft lookup table (query soft-matches keys, returns weighted values).

Vision Transformer (ViT, "an image is worth 16×16 words")

224×224 image, 16×16 patches → (224/16)² = 14×14 = 196 tokens (+1 class token = 197)
flattened patch = 16·16·3 = 768 → linear projection → token embedding. Pixels as tokens: 224² tokens → 224⁴ ops, impossible.
  • Token/visual word = patch. Prepend a learnable class token; MLP head on the class token at the final layer.
  • Global info comes from multi-head self-attention; class token at final layer summarises all patch tokens.
  • ViT: naturally global, finds long-range dependencies between patches, needs massive data (ImageNet-21K, JFT-300M) – keeps improving with data, while CNN plateaus. More robust than CNNs to occlusion, distribution shift, adversarial perturbation, patch permutation. Low layers: local+global heads; high layers: global.
  • CNN: inductive biases (locality, translation invariance) → OK on small data, but lacks global understanding.
CNN drawbacks: can't capture global info; can't capture spatial relationships of local objects; locality-sensitive. "Captures local info" and "combines local patterns" are strengths, not drawbacks.

Swin Transformer (hierarchical, shifted windows)

3×H×W → patch partition 4×4 → 48×H/4×W/4 → linear embed C×H/4×W/4 → 2C×H/8×W/8 → 4C×H/16×W/16 → 8C×H/32×W/32 (blocks ×2, ×2, ×6, ×2)
Patch merging: concat 2×2 neighbouring patches (4C) → linear → 2C: [C, H/4, W/4] → [2C, H/8, W/8] (spatial ÷2, depth ×2)
  • W-MSA: split tokens into local windows (e.g. 4×4 patches), self-attention inside each window independently; same output shape; faster than global SA; but no cross-window communication.
  • SW-MSA: shift windows right & down → tokens interact across windows; same output shape. Swin block = W-MSA block then SW-MSA block (each + Add&Norm + FFN).

Fine-tuning pretrained ViT

  • Full: new class token + new MLP head, train on new dataset.
  • PEFT principle: insert additional components that favour (don't change) the original ViT computation; freeze backbone, fine-tune / optimise only the new components.
Prompt-tuning: learnable prompts inserted among the token embeddings
Adapter (in the pointwise FFN): f(X) = g(X) + σ(XWdown)Wup,   g(X) = σ(XW1)W2 frozen
LoRA (on WQ, WK, WV): WQ + BQAQ, W:[m,n], B:[m,r], A:[r,n], r ≪ m,n → r(m+n) trainable vs mn
★ Week 10 key concepts (what the quiz tests)
  • Self- and cross-attention both compute all tokens in parallel. Self-attention: Q, K, V from the source, captures intra-sequence dependencies. Cross-attention: Q from the target, K and V from the source, captures inter-sequence dependencies.
  • CNN drawbacks: no global information, can't capture spatial relationships between local objects, locality-sensitive.
  • ViT: token = patch, turned into an embedding by a linear projection; the class token is learnable; the MLP head sits on the class token at the final layer. Global information comes from multi-head self-attention, and the final class token summarises the image.
  • ViT is naturally global and finds long-range dependencies, but needs massive data: it can't be trained directly on small datasets. It is more robust than CNNs.
  • Swin: patches of [3, 4, 4] → [C, H/4, W/4]. Patch merging: concatenate 2×2 neighbours, then a linear layer → [2C, H/8, W/8] (half the size, double the depth).
  • W-MSA: attention inside each local window independently, same output shape, faster, but tokens only meet tokens in their own window. SW-MSA: windows shifted right and down so tokens interact across windows; same output shape.
  • PEFT: add components that keep the original ViT computation and train only them. Prompts go into the token embeddings, adapters into the pointwise FFN, LoRA into WQ, WK, WV.

WEEK 11 · Generative models: GAN & Diffusion

Density estimation

  • Explicit: learn pm(x) ≈ pd(x), e.g. GMM p(x) = Σk πkN(x|μk,Σk) fitted with EM; fails on high-dim / structured data (images, text). Implicit: learn generator G: z~p(z) → x̃ = G(z) that mimics data (GAN, VAE). Generative model's task: generate realistic examples imitating the dataset from noise.

GAN (Goodfellow 2014)

minG maxD J(G,D) = Ex~pd[log D(x)] + Ez~pz[log(1 − D(G(z)))]
D (ascent): ∇θd (1/M)Σ[log D(x(i)) + log(1 − D(G(z(i))))]
G (descent): ∇θg (1/M)Σ log(1 − D(G(z(i))))  ⟶ in practice maxG Ez log D(G(z)) (stronger gradient when fakes look fake); k = 1 D-step per G-step
D(x) = P(real | x) via sigmoid; 1 − D(x) = P(fake | x)
D*(x) = pd(x) / (pd(x) + pg(x)) = 1 / (1 + pg/pd)  (from ∂/∂D: pd/D − pg/(1−D) = 0)
J(D*,G) = JSD(pd‖pg) − 2 log 2 → min at pg* = pd; Nash equilibrium D*(x) = 0.5 ∀x
  • Analogy: G = counterfeiter making fake money; D = police detecting it. Stop at Nash equilibrium (no player can improve).
  • More overlap of pg, pd ⇒ D's job harder, accuracy → 50%, BCE loss larger. GAN ↔ JSD, f-GAN ↔ f-divergence, WGAN ↔ Wasserstein.
  • Mode collapse: fakes cover only a few modes, miss others; source: nothing constrains G to cover all modes. Issues: mode collapse, unrealistic images on complex data (ImageNet), unstable training (min-max, no unique loss). Conditional GANs work better.
  • Inception score (higher = better): p(y|x̃) confident (low entropy) & average p(y) ≈ uniform (diverse): IS ≈ Ez[KL(p(y|G(z)) ‖ p(y))].
  • DCGAN: strided conv in D, fractional-strided (transposed) conv in G, no pooling; BatchNorm in both; no FC hidden layers; ReLU in G (tanh output); LeakyReLU in D. Latent arithmetic works.
ConvTranspose2d out = (in − 1)·s − 2p + k + output_padding    Conv2d out = ⌊(in + 2p − k)/s⌋ + 1
Example: Linear(100→7·7·256) → Unflatten(256,7,7) → ConvT(256→128, k5, s3, p2): (7−1)·3 − 4 + 5 = 19 → (16,128,19,19)

Diffusion models (DDPM)

Forward: q(xt|xt−1) = N(√(1−βt) xt−1, βtI),   xt = √(1−βt) xt−1 + √βt ε
αt = 1 − βt,   ᾱt = ∏i≤t(1 − βi),   xt = √ᾱt x0 + √(1−ᾱt) ε, ε ~ N(0,I); ᾱt→0 ⇒ xT ~ N(0,I)
Reverse: pθ(xt−1|xt) = N(μθ(xt,t), σt²I); q(xt−1|xt) intractable, q(xt−1|xt,x0) tractable
μθ = (1/√αt)(xt − βt/√(1−ᾱt) · εθ(xt,t));   σt² = βt or (1−ᾱt−1)βt/(1−ᾱt)
Loss: min E ‖ε − εθ(xt, t)‖²   Sample: xT~N(0,I); xt−1 = μθ + σtz, down to x0
  • Forward = shrink + add noise to clean images (closed form, no learning). Backward = start from noise, denoise each step (U-Net).
  • U-Net εθ(xt,t): residual blocks + self-attention; inputs xt and time embedding; predicts the added noise ε; crucial for denoising; does NOT do the forward pass.
  • Noise schedule: linear (2nd half almost pure noise) vs cosine (noises more slowly).
  • Latent diffusion (Stable Diffusion): encoder ℰ / decoder 𝒟, diffuse z0 = ℰ(x0) in latent space (faster); condition via cross-attention: Q = WQφ(zt), K,V = W·τθ(y); loss ‖ε − εθ(zt, t, τθ(y))‖².
★ Week 11 key concepts (what the quiz tests)
  • A generative model's job: generate realistic examples that imitate the dataset, starting from noise.
  • Noise goes into G, not D. D separates real from fake (high score for real, low for fake) and so measures the gap between pg and pd; G mimics real data. G = counterfeiter, D = police.
  • Objective: minG maxD E log D(x) + E log(1−D(G(z))). Swapping the two logs (labelling real 0, fake 1) is also valid; maxG minD is the wrong order.
  • Alternating updates: maxD J, then for G either min E log(1−D(G(z))) (original) or max E log D(G(z)) (used in practice).
  • When pg and pd overlap more, D's job gets harder, its accuracy approaches 50% and its BCE loss gets larger.
  • D ends in a sigmoid; D(x) = P(real), 1−D(x) = P(fake). D* = pd/(pd+pg) = 1/(1+pg/pd). At the Nash equilibrium D* = 0.5 and pg = pd.
  • Mode collapse = generated data covers only a few modes. Causes: the min-max problem can't be solved perfectly, and nothing forces G to cover all modes. Training issues: mode collapse, unrealistic images on complex data, unstable training.
  • Transposed-conv output = (I−1)·S − 2P + K + output_padding: (7−1)·3 − 4 + 5 = 19.
  • Forward process = shrink the image and add noise; backward = start from noise and denoise step by step. Correct forward formulas: xt = √(1−βt)xt−1 + √βtε and xt = √ᾱtx0 + √(1−ᾱt)ε (wrong options swap x0 and ε, or run t backwards).
  • The U-Net is trained by minimising ‖εθ(xt,t) − ε‖², predicts the added noise and does the denoising; it does not perform the forward process.
